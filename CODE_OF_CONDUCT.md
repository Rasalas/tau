# Code of conduct

Tau follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, argue about code and not about people, and
assume good faith. Harassment, insults, and personal or political attacks are
not welcome in issues, pull requests, discussions or anywhere else this project
lives.

Report unacceptable behaviour privately to the maintainer,
[@Rasalas](https://github.com/Rasalas), at the contact address on that GitHub
profile. Reports are handled confidentially.
The maintainer may remove comments, lock threads, or block people who break
these rules.
