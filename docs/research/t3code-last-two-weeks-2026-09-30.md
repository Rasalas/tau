# T3 Code additions, 16–30 September 2026

Research date: 30 September 2026. Sources are the live GitHub REST API, upstream release notes, merged PR descriptions, and source/docs pinned to the stable tag. The date window is 2026-09-16 00:00 UTC through 2026-09-30. Dates below use UTC. This note describes upstream T3 Code, not Tau's implementation.

## Released versions

- [v0.0.42](https://github.com/pingdotgg/t3code/releases/tag/v0.0.42) published 16 September at 04:59 UTC. Its long changelog includes changes merged before this window. Publication within the window does not make all its features new within the window.
- [v0.0.43](https://github.com/pingdotgg/t3code/releases/tag/v0.0.43) published 29 September at 19:14 UTC. It includes the user-facing changes listed below.
- [v0.0.44](https://github.com/pingdotgg/t3code/releases/tag/v0.0.44) published 29 September at 20:48 UTC. This is the latest stable release. Its additional change fixes Pro Max plan decoding so Codex's existing service-tier picker offers Ultrafast where the account/model supports it.
- [v0.0.45-nightly.20260930.2493](https://github.com/pingdotgg/t3code/releases/tag/v0.0.45-nightly.20260930.2493) published 30 September at 16:08 UTC. Its target is `c2fa9fc911daeac97df4760f95fc57dca42b84c8`, also the observed main HEAD. There is no additional unreleased main-only feature at that point.

The [stable-to-main comparison](https://github.com/pingdotgg/t3code/compare/v0.0.44...c2fa9fc911daeac97df4760f95fc57dca42b84c8) contains 14 commits. The main capability addition beyond stable is updated Codex 0.159 protocol bindings. Other changes fix OpenCode account-limit deduplication, Grok crash recovery, question rows, workspace links, PR badge routing/tooltips, diff clipping, and setup wording. The regenerated protocol does not by itself establish a new visible gateway login feature. [PR #14311](https://github.com/pingdotgg/t3code/pull/14311), merged 29 September at 20:31 UTC, recommends Codex >=0.159 for T3 >=0.0.44 while keeping 0.156 supported. It is outside the v0.0.44 tagged commit despite merging before that release's publication.

## General capabilities that predate the window

- Simulator/emulator support, separate agent consent, streams, touch/keyboard controls, `device_*` tools, concurrent devices across hosts and SSH device hosts were merged on **10 September**, not in these last two weeks. [#10677](https://github.com/pingdotgg/t3code/pull/10677), [#10854](https://github.com/pingdotgg/t3code/pull/10854), [#10855](https://github.com/pingdotgg/t3code/pull/10855), [#10856](https://github.com/pingdotgg/t3code/pull/10856). Current device toolbar includes accessibility settings/overlays, text size, theme, location, app permissions, orientation and platform-specific controls. [Stable devices guide](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/devices.md).
- T3 Connect managed relay tunnels and APNs were merged **5 June**. [#2837](https://github.com/pingdotgg/t3code/pull/2837). Current remote access also offers LAN/private pairing, Tailscale HTTPS, desktop-managed SSH server bootstrap and revocable device sessions. [Stable remote-access guide](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/remote-access.md). Newer headless device authorization merged **14 September**. [#11794](https://github.com/pingdotgg/t3code/pull/11794).
- Host CPU/memory-based automatic balancing of new threads merged **6 September**. Opt-in web/desktop; mobile manual. [#9895](https://github.com/pingdotgg/t3code/pull/9895).
- Android push notifications and ongoing activity cards merged **9 September**; Android 16+ may show Live Updates. [#10416](https://github.com/pingdotgg/t3code/pull/10416). Native iOS/Android pooled subscription widgets merged **13 September**. [#11506](https://github.com/pingdotgg/t3code/pull/11506). iOS Live Activities existed earlier; their iOS 26 glass correction merged **13 September**. [#11604](https://github.com/pingdotgg/t3code/pull/11604). Background push needs T3 Connect rather than direct/Tailscale alone. [Stable notification guide](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/mobile-notifications.md).
- Offline iPhone dictation merged **31 August**. On-device Apple speech model, supported iPhones with iOS 26+, up to five minutes, transcript review before sending. [#8614](https://github.com/pingdotgg/t3code/pull/8614).
- GitHub operations can use credentials from another trusted connected environment when both verify the same account/host. Read or read-and-action routing is opt-in and excludes disabled environments; ambiguous writes are not retried. Merged **13 September**. [#11367](https://github.com/pingdotgg/t3code/pull/11367).
- Same Codex thread can switch compatible accounts sharing CODEX_HOME, with a separate shadow home for credentials. This already existed before September; shared MCP OAuth lock fix merged **17 July**. [#4104](https://github.com/pingdotgg/t3code/pull/4104), [stable account-switch guide](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/providers-codex.md#switch-accounts-in-an-existing-thread). This does not establish arbitrary switching across independent homes.
- WSL support predates the window. Its archive-based backend packaging merged **14 September**. [#11511](https://github.com/pingdotgg/t3code/pull/11511). Preview SSH archive bootstrap also merged **14 September**, avoiding remote Node/npm dependency. [#11319](https://github.com/pingdotgg/t3code/pull/11319).
- Six native provider integrations and native iOS/Android clients are documented in the [stable README](https://github.com/pingdotgg/t3code/blob/v0.0.44/README.md). Browser-cookie import and global window-plus-accessibility capture are general capabilities, without asserting a first introduction date here. [Browser import](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/browser-import.md), [SnapShots](https://github.com/pingdotgg/t3code/blob/v0.0.44/docs/user/snap-shot.md).

## Claims to exclude or qualify

- [#12983](https://github.com/pingdotgg/t3code/pull/12983), merged 23 September, adds shared sign-in/credential APIs but expressly adds no provider-specific sign-in or visual change. Managed ChatGPT auth is the later user-facing implementation.
- [#11966](https://github.com/pingdotgg/t3code/pull/11966) appears in a 16 September nightly but actually merged 15 September at 21:43 UTC. It is mobile build configuration, not a first mobile release.
- [#12351](https://github.com/pingdotgg/t3code/pull/12351) adds mobile scheduled-task screens and merged 18 September into `t3code/codex-turn-mapping`, not main. The stable source tree and stable release notes do not contain that feature. Do not claim it shipped in v0.0.43/44.
- Mobile source merged/release configuration is not proof that a corresponding binary has already cleared every app-store review. Stable desktop/CLI feature availability is verified through tags; latest mobile-store rollout was not independently checked.
